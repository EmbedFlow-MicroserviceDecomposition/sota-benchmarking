# MAGNET Tool Adapter

This directory contains the wrapper and adapter for the **MAGNET** microservice decomposition tool.
The core tool is tracked as a Git submodule in the `MAGNET/` directory.

## Structure
- `MAGNET/`: Git submodule containing the original source code for MAGNET.
- `Dockerfile` (To be added): Containerized environment for running MAGNET with its specific dependencies.
- Scripts/Adapters (To be added): Pre-processing and post-processing scripts to adapt standard datasets to MAGNET's input format and standard metric evaluation format.
