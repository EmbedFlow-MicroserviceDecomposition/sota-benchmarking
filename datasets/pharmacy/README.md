# Pharmacy Dataset

This directory contains the monolithic dataset and adapter for **Pharmacy**, an open-source Java application.

The original monolithic application is tracked as a Git submodule in the `pharmacy/` directory.

## Structure
- `pharmacy/`: Git submodule containing the monolithic source code.
- `dataset.py`: Python script utilizing `javalang` to traverse the Java source code, extract all class/method signatures, and locate the required `pharmacy_kdm.xmi`. It outputs this structured data to `dataset.json`.
- `pharmacy_kdm.xmi`: The KDM Code Model XMI generated by Eclipse MoDisco.

## Eclipse MoDisco Generation

To generate the Call Graph XMI required by decomposition tools:
1. Open Eclipse and navigate to **File > Import > General > Existing Projects into Workspace** (or Maven if it is a Maven project).
2. Select the `datasets/pharmacy/pharmacy` directory and import it.
3. Right-click the project in the Package Explorer.
4. Select **Discovery > Discoverers > Discover KDM Code and Build Models from Java Project**. 
   *(Note: If 1-step generation fails, use the manual 2-step process: Discover Java Model -> Discover KDM Model from Java Model).*
5. Export or rename the resulting XMI file to `pharmacy_kdm.xmi` and place it in this directory (`datasets/pharmacy/`).

## Usage

Run the adapter script using `uv`:

```bash
uv run dataset.py
```

This will parse all Java files inside the `pharmacy` repository and output the standardized `dataset.json` file.
