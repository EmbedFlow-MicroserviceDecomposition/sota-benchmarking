# SpringBlog Dataset

This directory contains the monolithic dataset and adapter for **SpringBlog**, a simple blog application built with Spring Boot.

The original monolithic application is tracked as a Git submodule in the `SpringBlog/` directory.

## Structure
- `SpringBlog/`: Git submodule containing the monolithic source code.
- `dataset.py`: Python script utilizing `javalang` to traverse the Java source code, extract all class/method signatures, and locate the required `SpringBlog_kdm.xmi`. It outputs this structured data to `dataset.json`.
- `SpringBlog_kdm.xmi`: The KDM Code Model XMI generated by Eclipse MoDisco.

## Eclipse MoDisco Generation

To generate the Call Graph XMI required by decomposition tools:
1. Open Eclipse and navigate to **File > Import > Maven > Existing Maven Projects**.
2. Select the `datasets/spring-blog/SpringBlog` directory and import it.
3. Wait for Eclipse to resolve all Maven dependencies.
4. **Manual 2-Step Generation:**
   - Right-click the `SpringBlog` project > **Discovery > Discoverers > Discover Java Model from Java project**.
   - Right-click the resulting `SpringBlog_java.xmi` > **Discovery > Discoverers > Discover KDM Model from Java Model**.
5. Export or rename the final XMI file to `SpringBlog_kdm.xmi` and place it in this directory (`datasets/spring-blog/`).

## Usage

Run the adapter script using `uv`:

```bash
uv run dataset.py
```

This will parse all Java files inside the `SpringBlog` repository and output the standardized `dataset.json` file.
