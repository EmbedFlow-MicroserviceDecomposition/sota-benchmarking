# Acme Air Dataset

This directory contains the monolithic dataset and adapters for **Acme Air**.
The original application is tracked as a Git submodule in the `acmeair/` directory.

## Structure
- `acmeair/`: Git submodule containing the Acme Air monolithic source code.
- `Dataset: Monolith Adapter` (To be added): Script to extract the structural dependency graph or generic IR from the monolith.
- `Dataset: Microservice Adapter` (To be added if ground truth exists): Script to extract the standard microservice architecture mapping.
